# Related projects

These three projects were built together with the same method: reverse-engineer a
product with [REA](https://github.com/morluto/rea) to recover its **behaviour and
architecture**, then write an independent implementation from scratch.

| Project | What it is | Stack |
| --- | --- | --- |
| [open-obsidian](https://github.com/JingHao-Leon/open-obsidian) | Local-first Markdown knowledge base: wikilinks, backlinks, graph view, plugin API | TypeScript · React |
| [open-raycast](https://github.com/JingHao-Leon/open-raycast) | macOS launcher: fuzzy search, calculator, clipboard history, snippets | Swift · SwiftUI · AppKit |
| [open-todoist](https://github.com/JingHao-Leon/open-todoist) | Local-first task manager with natural-language quick add | TypeScript · React |

Each project is MIT licensed and is **not affiliated** with the product whose name
it references.
